EDUNEXA COLLEGE - FILES SHARED OUTSIDE GITHUB
=============================================

These files hold passwords and private keys. They are NOT in the GitHub repository (git ignores
them). Share them privately (password manager / direct transfer), never by GitHub, chat groups or
email attachments. Paths are relative to the repository folder "edunexa-college".


1) Firebase server key (phone push notifications)
   Put it at:   backend/secrets/fcm-service-account.json
   Then make sure backend/.env contains this line (use the full path on that machine):
       EDUNEXA_FCM_SERVICE_ACCOUNT_FILE=<full path to>/backend/secrets/fcm-service-account.json
   Needed only on machines that RUN THE BACKEND and must send push notifications
   (the live server 150.241.246.34, or a developer testing pushes). Not needed to build the apps.
   Keep it private: chmod 600 backend/secrets/fcm-service-account.json

2) Backend settings
   Put it at:   backend/.env
   Holds the database connection, JWT secret, S3 file storage keys and the Firebase key path.
   Needed on every machine that runs the backend.

If the Firebase server key is ever exposed or someone leaves the team:
   Firebase console > Project settings > Service accounts > generate a new private key,
   delete the old key in Google Cloud > IAM > Service accounts, and share the new file again.
