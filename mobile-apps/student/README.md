# EduNexa Student Flutter app

Generated Android and iOS project, with a role-specific module outline. This is a starter, not the complete native implementation of the existing mobile web screens.

Run `flutter pub get`, `flutter analyze`, then `flutter run`. Android requires an Android SDK/emulator. iOS builds require Xcode, signing and an Apple developer setup. Configure signing for your own team before distribution.

Planned modules: Profile and timetable, Attendance, Assignments and resources, Exam results, Fees, library, hostel and transport. No login, API calls, push notifications, payment integration, or local production storage are configured. The backend folder is intentionally empty. Use database/schema-catalog.json and client-data/initial-data-entry/import-contract-v2.json when designing the future Python API. Do not access SQL directly from Flutter.
